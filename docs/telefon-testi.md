# Telefon test listesi (Android deneme sürümü)

Her adımı sırayla dene. Beklenen sonuç olduysa ✓, olmadıysa ✗ koy ve ekranın görüntüsünü al.
Ustanın adımları için ikinci bir e-posta adresi gerekir (ör. başka bir Gmail).

| # | Ne yap | Ne olmalı | ✓ / ✗ |
| --- | --- | --- | --- |
| 1 | EAS'ın verdiği bağlantıdan APK'yı indir, aç, "bilinmeyen uygulamalara izin ver" deyip kur. | BoyaCep simgesi ana ekranda; açılışta yeşil karşılama ekranı. | |
| 2 | Giriş yapmadan **Ne Kadar Boya?** ile bir oda hesapla (ör. 4 × 3 m, 2,7 m yükseklik, 1 kapı). | Litre, kat ve kutu sayısı çıkar; sayının yanında "tahmin" gibi kaynak etiketi görünür. | |
| 3 | Profil → Giriş yap. E-postanı yaz, gelen e-postadaki bağlantıya telefondan dokun. | Bağlantı BoyaCep'i açar ve giriş yapılmış olur. | |
| 4 | Projeler → yeni proje aç, bir oda ekle (ölçüler, 1 kapı, 1 pencere), kaydet. | Oda listede; boya ve malzeme miktarı görünür. | |
| 5 | Projede **Maliyet**'e gir, bir işçilik tutarı ekle. | Toplam güncellenir; fiyatların tahmin olduğu yazar. | |
| 6 | Projeye kameradan bir duvar fotoğrafı ekle. | Kamera izni sorulur; fotoğraf projede görünür. | |
| 7 | **Renk Stüdyosu**'nda bir oda fotoğrafı aç, duvara dokun. | Sadece duvar seçilir; tavan ve eşyalar dışarıda kalır. | |
| 8 | Duvara karışan bir eşya varsa **Çıkar**'ı seçip o eşyaya dokun. | Eşya seçimden çıkar. | |
| 9 | Birkaç renk dene; ışık ve gölgeye bak. | Renk duvarın gölgesini ve dokusunu korur, düz boya gibi durmaz. | |
| 10 | Beğendiğin rengi **projeye kaydet**. | "Kaydedildi" mesajı; projede renk görünür. (Canlı veritabanı güncellenmeden hata verir.) | |

| 12 | Projede **Paylaş** → kod oluştur. | 8 harfli kod ve "en fazla 3 usta katılabilir (0 katıldı)" yazısı. | |

| 14 | Usta olarak bu projeye teklif yaz ve gönder. Sonra ev sahibi hesabına dön, teklifi aç, **Kabul et**. | Teklif "Kabul edildi" olur. Ustanın telefonu teklifte **görünmez**. | |
| 15 | Projede **Keşif dosyası**'nı aç, **PDF olarak paylaş**'a dokun. Usta hesabında da paylaşılan projeden **Keşif dosyasını aç**. | Odalar, boya miktarı, renkler ve kaydettiğin inceleme tek ekranda ve PDF'te görünür; ustada bütçe görünmez. | |
| 16 | Teklifte **PDF olarak paylaş**; Profil → **Verilerimi indir**; sonra **Çıkış yap**. | PDF paylaşım ekranı açılır; veri dosyası iner; çıkıştan sonra giriş ekranı gelir. | |
