# Telefon test listesi (Android deneme sürümü)

Bu liste, hesap gerektiren kısımlar için. Giriş yapmadan çalışan kısımlar (hesaplama, Renk Stüdyosu, Duvarını İncele, fiyatlar, rehber) emülatörde denendi ve geçti.

Her adımı sırayla dene. Olması gereken olduysa ✓, olmadıysa ✗ koy ve ekranın görüntüsünü al. Bir adım takılırsa atla, sonrakine geç.

## Ev sahibi olarak

| # | Ne yap | Ne olmalı | ✓ / ✗ |
| --- | --- | --- | --- |
| 1 | Bağlantıyı telefonda aç, APK'yı indir ve kur. Telefon sorarsa "bilinmeyen uygulamalara izin ver" de. | BoyaCep açılır, karşılama ekranı gelir. | |
| 2 | **Profil → Giriş yap**. E-postanı yaz. E-postana gelen bağlantıya dokun ya da kodu yaz. | Giriş yapılmış olur. | |
| 3 | **Boya Hesapla → Oda Seç** ile bir oda hesapla. Sonuçta **Projeye kaydet**'e dokun, yeni bir proje adı yaz. | Proje **Projelerim**'de görünür, oda ve boya miktarı içinde. | |
| 4 | Projede **Maliyet**'e gir, bir işçilik tutarı ekle. | Toplam değişir, fiyatların tahmin olduğu yazar. | |
| 5 | Projede **Fotoğraf ekle** ile kameradan bir duvar fotoğrafı çek. | Kamera izni sorulur, fotoğraf projede görünür. | |
| 6 | Projede **Akıllı Bütçe → Harcama ekle**. Tutar yaz, fiş fotoğrafı ekle, kaydet. | Harcama listede görünür, **Fişi aç** ile fiş açılır. | |
| 7 | **Renk Stüdyosu**'nda odanın fotoğrafını çek, duvara dokun, bir renk seç, **Projeye kaydet**. | "projeye kaydedildi" yazar, renk projede görünür. | |
| 8 | **Duvarını İncele**'de bir belirti seç (ör. kabarma), sonra **Projeye kaydet**. | **Keşif dosyasını aç** düğmesi çıkar. | |
| 9 | Projede **Keşif dosyası**'nı aç, **PDF olarak paylaş**'a dokun. | PDF açılır; odalar, boya miktarı, renk ve inceleme içinde. | |
| 10 | Projede **Ustayla paylaş → Paylaşım kodu oluştur**. | 8 harfli bir kod çıkar. | |
| 11 | **Profil → Ev Hafızası → Kayıt ekle**. Nereyi boyadığını ve tarihi yaz, kaydet. Sonra **Zamanı gelince hatırlat**'ı aç. | Kayıt listede görünür, bildirim izni sorulur. | |
| 12 | **Profil → Hesap Bilgileri → Verilerimi indir**, sonra **Çıkış yap**. | Veri dosyası iner. Çıkıştan sonra giriş ekranı gelir. | |
